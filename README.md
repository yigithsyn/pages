# Paper V2

This project contains the HTML template for Paper V2, which includes Bootstrap v6 for styling and responsive design. The template is structured with a basic HTML5 skeleton and includes the necessary Bootstrap CSS and JS files.

## Project structure

- `index.html` contains the page markup and asset references.
- `css/app.css` imports the page-specific stylesheets.
- `css/header.css` contains header-specific styles.
- `css/sidebar.css` contains sidebar and responsive drawer styles.
- `css/workspace.css` contains workspace, page, text box, and print styles.
- `js/app.js` initializes the page modules.
- `js/header.js` contains header menu and theme behavior.
- `js/sidebar.js` contains sidebar and responsive drawer behavior.
- `js/workspace.js` contains workspace pages, text boxes, import/export, and printing.
- `js/theme-init.js` applies the saved or system color mode before the page is rendered.
- `js/markdown.bundle.js` is built from `src/markdown.js`.
